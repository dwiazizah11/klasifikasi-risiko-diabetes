# Klasifikasi Status Risiko Diabetes Guna Mendukung Upaya Deteksi Dini Diabetes

# Deskripsi
Klasifikasi status risiko diabetes menggunakan Machine Learning dengan algoritma Decision Tree untuk memprediksi kategori Low Risk dan High Risk berdasarkan usia, BMI, kadar glukosa, aktivitas fisik, riwayat keluarga, dan kebiasaan merokok. Model dilatih dan dievaluasi menggunakan dataset diabetes, dengan hasil akurasi sebesar 92,09%, serta digunakan untuk mengklasifikasikan data baru guna mendukung upaya peningkatan kesehatan yang sejalan dengan SDGs 3.
